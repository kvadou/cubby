# Phase 3 plan: auth, center scoping, director inbox

Decisions and evidence: [`docs/prior-art/2026-10-19-phase3-auth.md`](../prior-art/2026-10-19-phase3-auth.md).

## Done when
Request specs prove one center cannot read or change another's data (O1), the auth and CSRF obligations (O2 to O6) pass, and the full loop works in a browser at desktop and phone widths: sign in, see the inbox, approve with an edited message, dismiss with a reason, snooze, see approved items, sign out.

## API

| Method | Path | Notes |
| --- | --- | --- |
| POST | `/api/v1/session` | `{email_address, password}`; sets the cookie; returns `me` |
| DELETE | `/api/v1/session` | Destroys the session row, clears the cookie |
| POST | `/api/v1/tokens` | Mobile; returns `{token, me}` once |
| DELETE | `/api/v1/tokens/current` | Revokes the bearer session |
| GET | `/api/v1/me` | `{user, centers}` |
| GET | `/api/v1/centers/:center_id/proposed_actions` | Existing, now scoped, adds `lock_version`, `final_body`, `decided_by_name` |
| POST | `.../proposed_actions/:id/approve` | `{lock_version, final_body}`; `final_body` required for family-facing kinds |
| POST | `.../proposed_actions/:id/dismiss` | `{lock_version, reason}` |
| POST | `.../proposed_actions/:id/snooze` | `{lock_version, until}`; future, at most 30 days |

Errors: 401 `unauthenticated`, 403 `forbidden_origin`, 404 `not_found` (including other centers), 409 `conflict` with the current action, 422 `invalid`, 429 `rate_limited`.

## Schema

```ruby
create_table :users do |t|
  t.string :name, null: false
  t.string :email_address, null: false, index: { unique: true }
  t.string :password_digest, null: false
  t.timestamps
end

create_table :sessions do |t|
  t.references :user, null: false, foreign_key: true
  t.string :kind, null: false            # cookie | bearer
  t.string :token_digest, index: { unique: true }
  t.string :ip_address
  t.string :user_agent
  t.datetime :expires_at, null: false
  t.timestamps
end

create_table :memberships do |t|
  t.references :user, null: false, foreign_key: true
  t.references :center, null: false, foreign_key: true
  t.string :role, null: false, default: "director"
  t.timestamps
  t.index %i[user_id center_id], unique: true
end
```

## Request guard (D3)

```ruby
def verify_same_origin
  return if request.get? || request.head? || bearer_token.present?
  site = request.headers["Sec-Fetch-Site"]
  ok = site.present? ? site == "same-origin" : allowed_origin?(request.headers["Origin"])
  render json: { error: "forbidden_origin" }, status: :forbidden unless ok
end
```

## Web app (`web/`)
Vite + React + TypeScript (strict), TanStack Query, React Router. Vite proxies `/api` to `localhost:3000` so cookies stay same origin. Screens: sign in, inbox (cards grouped by kind, with rationale and facts), approve drawer with an editable message, dismiss modal with a reason, snooze menu, approved list, sign out. No native dialogs. Keyboard reachable, labelled controls, visible focus, responsive at 375 px.
