# Prior art: Cubby phase 4 drafting, retrieval, agent, evals

Retrieved 2026-10-19. Research record for the phase 4 build.

## Decision first

- **Recommendation:** Draft through Bedrock Converse with a single forced tool (`toolChoice.tool`) whose schema is the draft, from minimal facts plus handbook sections retrieved by Titan Text Embeddings V2 (1024, normalized) in pgvector with an HNSW cosine index. Gate every draft with deterministic checks, and allow one retry that feeds back the failed checks. Grade tone and clarity only in evals, with a different model as judge, and replay recorded responses in CI. Ask Cubby uses read-only, center-scoped tools in a bounded loop (D1 to D7).
- **Evidence:** Converse's `ToolChoice` union forces a named tool on Anthropic Claude 3+ models (E2). The installed SDK exposes `tool_choice` and `strict` (E1). Titan V2 accepts `dimensions` 1024/512/256 and `normalize` (E3). neighbor documents `has_neighbors` and HNSW `vector_cosine_ops` (E4). Anthropic recommends code-graded checks first, LLM grading with rubrics, and volume over hand grading (E5). OWASP LLM01 says to segregate untrusted content, use least privilege, and keep a human in the loop (E6).
- **Limitation:** no live model call has succeeded through Cubby's code. The new AWS account went from "use case form not submitted" to "Error 002: Access to Bedrock models is not allowed for this account" during the session, and that also blocks Titan, which had worked an hour earlier (E7). Live obligations O7 to O9 stay open.
- **Next check:** once Bedrock access is restored, run `bin/rails cubby:policies:index`, `bin/rails cubby:draft`, and `EVALS_LIVE=1 bin/rails evals:drafts`, then commit the recordings.

## Limits

- Model pricing in `Ai::Bedrock::PRICES` ($1/$5 per million tokens for Haiku 4.5, $3/$15 for Sonnet 4.5) is from prior knowledge, not verified this session.
- The Converse tool-use user guide was not readable (an empty fetch); support for `tool_choice.tool` on Claude 4.5 rests on the API reference's "Claude 3" wording plus the brief successful CLI calls, not a tool-forced live call.
- The judge model grading its own family (Sonnet judging Haiku) is a weaker separation than a different vendor.
- Independent security review of commit 9496fff (2026-10-19): no HIGH. Fixed: money and fee checks now catch written-out amounts ("40 dollars") and fees called charges or penalties, blank names fail, network timeouts count as Bedrock unavailable (503, failed draft), client timeouts plus a 45 s Ask deadline, a draft is marked failed when Sidekiq retries run out, model-chosen tool inputs are coerced, classroom lookup is exact, recorder keys include max_tokens and temperature, and policy search uses pgvector iterative scan so a small center still gets its sections.
- Review triggers: Bedrock access restored (run O7 to O9), a move to 5.x models, the handbook growing past one-section chunks, a new kind of family-facing action.
